# Vision-Pro 0.1.2

Quittez complètement l'ancienne application, puis lancez Vision-Pro_0.1.2_x64-setup.exe. Le fichier vision-pro.exe est la version portable, à utiliser à la place de la version installée, sans lancer les deux simultanément.

## Première association

1. Sur le PC : Connecter un iPad.
2. Sur l'iPad : ouvrir https://vision-pro.34-73-186-88.sslip.io et saisir le code du PC.
3. Dans la même fenêtre sur le PC : vérifier le code de comparaison, puis cliquer « Associer cet iPad » à la troisième étape.
4. Le message confirme que l'iPad est associé et mémorisé. Cliquer « Terminé ».

## Connexions suivantes

Sur le même iPad, dans le même navigateur et à la même adresse, sélectionner l'ordinateur puis « Connecter ». La clé de l'iPad est conservée dans les données du site ; le PC conserve l'autorisation. Aucun compte ou code à ressaisir avec les réglages par défaut. Le PC doit rester allumé et Vision-Pro lancé ; les deux appareils doivent disposer d'Internet.

Une nouvelle association est nécessaire si l'autorisation est révoquée, si les données Safari sont effacées, si l'identité est réinitialisée ou si la confiance expire (90 jours d'inactivité par défaut). Évitez la navigation privée pour garder l'association. L'option « Confirmer chaque connexion » peut toujours imposer une validation PC.

Cette version corrige uniquement la fenêtre Windows ; le site et le relais déjà en ligne sont compatibles. Aucun compte ni certificat à installer sur l'iPad.

Installateur non signé Authenticode : Windows peut signaler un éditeur inconnu. L'installation n'a pas été exécutée automatiquement. Les sommes SHA-256 sont fournies dans SHA256SUMS.txt.
